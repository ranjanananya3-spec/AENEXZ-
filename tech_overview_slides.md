## Slide 2: Technology Stack & Engineering Ecosystem

### 📋 Slide Text (Keep on screen)
* **Programming Core**: **Python 3** (Industry standard for scientific machine learning).
* **Data Engineering**: **Pandas** & **NumPy** (Used for dataset verification, types validation, and missing value checks).
* **Machine Learning**: **Scikit-Learn**
  * Train/test splitting.
  * Cross-validated modeling: baseline OLS, L1 (LassoCV), and L2 (RidgeCV).
* **Statistical Diagnostics**: **Statsmodels** (Variance Inflation Factor (VIF) scores).
* **Data Visualization**: **Seaborn** & **Matplotlib** (Heatmaps, fit lines, and Q-Q plots).

### 🗣️ Presenter Talking Points (What to say)
> *"On the technical side, we built this project using a modern Python stack. We utilized Pandas and NumPy to ingest and validate the raw patient metrics. For machine learning, we chose Scikit-Learn, which handled data splitting and trained our regression models. To resolve severe multicollinearity, we used Statsmodels for VIF scoring, and all regression diagnostic charts were built using Seaborn and Matplotlib."*
