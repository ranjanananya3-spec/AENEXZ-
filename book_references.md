# Academic Book References

You can use the following authoritative textbooks on statistical learning, linear regression diagnostics, and machine learning to reference the theoretical foundations of this project.

---

## 1. The Gold Standard for Statistical Learning
### An Introduction to Statistical Learning (with Applications in Python)
* **Authors**: Gareth James, Daniela Witten, Trevor Hastie, and Robert Tibshirani.
* **Edition/Year**: 1st Python Edition, 2023 / 2nd Edition, 2021.
* **Publisher**: Springer
* **ISBN**: 978-3-031-38746-3
* **Key Topics Covered**: Linear Regression (Chapter 3), Shrinkage Methods, Ridge & Lasso Regularization (Chapter 6), Cross-Validation (Chapter 5).
* **Significance**: The most accessible, modern textbook for machine learning foundations. Free digital versions are widely endorsed by the authors.

---

## 2. Advanced Mathematical Theory
### The Elements of Statistical Learning: Data Mining, Inference, and Prediction
* **Authors**: Trevor Hastie, Robert Tibshirani, and Jerome Friedman.
* **Edition/Year**: 2nd Edition, 2009.
* **Publisher**: Springer
* **ISBN**: 978-0-387-84857-0
* **Key Topics Covered**: Linear Methods for Regression (Chapter 3), L1 and L2 Shrinkage Path Algorithms.
* **Significance**: Written by the pioneering authors who created the Lasso and LAR methods. It provides the deep mathematical proofs and derivations for regularized linear systems.

---

## 3. Regression Analysis and Diagnostics (VIF, Residuals)
### Applied Linear Regression
* **Author**: Sanford Weisberg.
* **Edition/Year**: 4th Edition, 2014.
* **Publisher**: John Wiley & Sons
* **ISBN**: 978-1-118-38608-8
* **Key Topics Covered**: Diagnostics for curvature and non-constant variance, Residual plot analysis, Multicollinearity diagnostics, and Variance Inflation Factors (VIF).
* **Significance**: The definitive textbook for diagnostic validation, Q-Q plots, and assumption checking in linear models.

---

## 4. Classic Machine Learning
### Pattern Recognition and Machine Learning
* **Author**: Christopher M. Bishop.
* **Year**: 2006.
* **Publisher**: Springer
* **ISBN**: 978-0-387-31073-2
* **Key Topics Covered**: Linear Models for Regression (Chapter 3), Regularized Least Squares (L2 / Weight Decay).
* **Significance**: Highly respected classic textbook detailing regression from both Bayesian and Frequentist perspectives.
