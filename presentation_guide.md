## Slide 3: Strategic Vision (The Road Ahead)

### 📋 Slide Text (Keep on screen)
* **Vision**: Deliver low-latency, interpretable predictive pipelines to assist clinicians in real time.
* **Roadmap**:
  1. **Phase 1 (Current)**: Research baseline models, identify multicollinearity, and stabilize parameters.
  2. **Phase 2 (Near-Term)**: Deploy models as API microservices to integrate directly into EHR systems.
  3. **Phase 3 (Long-Term)**: Process real-time streaming data from wearable health IoT devices.
* **Impact**: Reduce diagnostic cost by 30% through regularized feature reduction (e.g., dropping redundant variables).

### 🗣️ Presenter Talking Points (What to say)
> *"Our strategic vision is to move from experimental research to live clinical decision systems. We are currently in Phase 1, validating baseline models. In Phase 2, we will package the model into APIs to connect with existing hospital EHR systems. In Phase 3, we plan to support live monitoring via wearables. By dropping redundant features using Lasso, we simplify clinical checklists, reducing data collection costs by roughly 30%."*
