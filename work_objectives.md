## Slide: Objectives of the Work

### 📋 Slide Text (Keep on screen)
* **Accurate Progression Modeling**: Develop a robust machine learning system to predict disease progression after one year.
* **Resolve Collinearity**: Diagnose and address severe multicollinearity in patient blood serum measurements.
* **Optimize Features**: Use regularization (L1/Lasso) to identify the most critical clinical variables and drop redundant ones.
* **Clinical Viability**: Verify statistical assumptions (residuals, normality) to ensure the model is auditable and deployable.

### 🗣️ Presenter Talking Points (What to say)
> *"Let's review the main objectives of this project. First, we aimed to build a highly accurate machine learning system to predict diabetes progression. Second, we wanted to address the severe multicollinearity present in the blood serum features. Third, we used regularization to perform feature selection, identifying the most critical variables so clinicians can focus on fewer tests. Finally, we verified all regression assumptions to make sure the model is stable and ready for clinical environments."*
